Política de Privacidade – aplicativo "subir_yt"

Responsável: Rafael de Oliveira, titular dos canais · Última atualização: 19 de outubro de 2026

1. O que é o aplicativo

O "subir_yt" é uma ferramenta pessoal, de uso exclusivo do responsável, que envia vídeos para os canais do YouTube de sua própria titularidade por meio da YouTube Data API. Ele não é oferecido ao público, não possui cadastro de usuários e não é operado por terceiros.

2. Dados acessados

Mediante autorização OAuth concedida pelo próprio responsável, o aplicativo acessa apenas o necessário para a finalidade acima: enviar vídeos, definir título, descrição, tags, miniatura, agendamento e playlist, e ler o nome do canal autorizado. Não são acessados dados de espectadores, comentários, mensagens, contatos ou qualquer informação de terceiros.

3. Como os dados são tratados

  • As credenciais de acesso (tokens OAuth) ficam armazenadas apenas no computador do responsável e nunca são transmitidas a outros servidores além dos da própria API do Google.
  • Nenhum dado obtido do YouTube é vendido, compartilhado, usado para publicidade ou transferido a terceiros.
  • O aplicativo não utiliza os dados para treinar modelos de inteligência artificial nem para qualquer finalidade diversa do envio de vídeos.

4. Política de dados do usuário dos Serviços de API do Google

O uso de informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, inclusive aos requisitos de Uso Limitado (Limited Use).

5. Revogação

A autorização pode ser revogada a qualquer momento na página de permissões da Conta Google (myaccount.google.com/permissions) ou pela exclusão do arquivo de token no computador do responsável.

6. Contato

Dúvidas sobre esta política podem ser enviadas pelo e-mail de contato informado na aba "Sobre" dos canais do responsável no YouTube.
